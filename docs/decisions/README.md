# Architecture decision records

Architecture decision records explain durable choices that affect multiple
features or contributors. They prevent a future implementation from losing the
reason behind a boundary.

Use the next four-digit number and this structure:

```markdown
# NNNN: Decision title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD

## Context
## Decision
## Consequences
## Alternatives considered
```

Update the status instead of rewriting history. A superseding decision links
to the record it replaces.
